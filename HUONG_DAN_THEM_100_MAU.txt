BREASTCARE AI V2.1 - THEM NUT TAO 100 MAU NGAU NHIEN

1. Dung Backend va Frontend trong VS Code bang Ctrl+C.
2. Sao chep file them_100_mau_ngau_nhien.py vao D:\breast_cancer_vscode
3. Mo Terminal VS Code:
   cd D:\breast_cancer_vscode
   python .\them_100_mau_ngau_nhien.py
4. Khoi dong Backend o Terminal 1:
   .\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
5. Khoi dong Frontend o Terminal 2:
   cd D:\breast_cancer_vscode\frontend
   npm.cmd run dev
6. Mo http://127.0.0.1:5173 -> Du doan hang loat.
   Bam nut 'Tao 100 mau ngau nhien'. Web se tu lay 100 mau tu dataset va du doan ngay.

API: GET http://127.0.0.1:8000/api/random-batch?count=100
